## 4. 技術的な理解
- enignx：Linux上にインストールするWebサーバ
- 【nginx起動において使用したコマンド】
- sudo systemctl start nginx：nginxを起動する
- sudo systemctl enable nginx：EC2起動時にnginxも起動する
- sudo systemctl status nginx：nginxの稼働状態を確認する
- curl http://localhost：nginxがWebページを返すか確認する
- ※systemctl：サービスそのものの状態を管理・確認する
- ※curl：実際に通信して、相手から応答が返ってくるか確認する
- HTTPポート80番を開放し、インバウンド通信を許可して、ブラウザからnginxにアクセスした

## 5. 設計理由
- EC2にnginxをインストールすることによって、EC2がwebサイトの情報を返す役割を可能にするため
- インバウンド通信を可能にするために、80番ポートを解放し、HTTP通信でブラウザからnginxにアクセスできるようにした
- 【nginxを用いる理由】
- nginxには、リバースプロキシ、静的ファイルの配信、負荷分散、セキュリティ/通信制御といった機能がある。
- 今回は、EC2上にソフトウェアをインストール、Linux上でサービスを起動/停止、HTTP通信の仕組みを理解、SGで通信を制御する経験などの目的がある。
