## 4. 技術的な理解
【1】
- ++：条件に応じて1増やす
- let：集計によって数量を変更する場合、constではなくletを使用する
- row.cells[3]：テーブルの4番目のセル

【2】
- document.createElement("select")：HTMLプルダウンを作成する
- document.createElement("option")：プルダウンの選択肢を1つずつ作成する
- select.value = originalData[2]：編集ボタンを押した時に現在の[2：利用者]を初期選択状態にする

【3】
- <select id="sortSelect">以下：プルダウンを作成、中身を決める
- addEventLisener("change"：変更を検知したときに動作
- tbody.querySelectAll("tr")：備品一覧にあるすべての行（tr）を取得（※この時点では通常の配列ではなく、NodeListという形式）
- Array.from()：↑を配列に変換
- const sortType = sortSelect.value;：プルダウンで選択されている値を取得
- textContent：そのセルに書かれている文字
- localeCompare()：文字列同士を比較する
